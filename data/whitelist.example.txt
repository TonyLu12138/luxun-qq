# ===========================================================================
#  luxun-qq 回复白名单（示例文件）
# ===========================================================================
#
#  用法：复制成 whitelist.txt 再改
#      copy data\whitelist.example.txt data\whitelist.txt
#
#  一行一个 QQ 号。只有写在这里的号发来的私聊，才会生成候选回复。
#  其他人发消息只记日志，不会打扰你。
#
#  改完**直接保存就生效**，不需要重启服务（按文件修改时间热加载）。
#
#  规则：
#    * 一行一个号码
#    * `#` 开头（或行内 `#` 之后）的内容都是注释，会被忽略
#    * 空行忽略
#    * 也可以在一行里写多个，用逗号/空格分隔，例如：
#          1234567890, 1987654321
#    * 号码至少 5 位数字，太短的会被忽略
#
#  想临时恢复「回复所有人」：
#    把 config.yaml 里的 bot.target_mode 改成 "all"
#
#  想彻底停掉回复：
#    把下面所有号码注释掉或删掉。名单为空时服务谁也不回，
#    并会在日志里提示一次。
#
# ===========================================================================


# ---- 允许回复的号（写在下面）---------------------------------------------

1234567890


# ---- 参考：其他人的号可以照这个格式加 -----------------------------------
#
# 1987654321
# 1122334455
#
# 注意：不要把你自己的号写进来。
# 你自己的消息只当审批指令（1/2/3/0/a/n/r/d）用，永远不会生成候选。
